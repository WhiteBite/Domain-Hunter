# Domain Hunter — массовая проверка доменов и генератор имён

[English](README.md) | **Русский**

[![License: MIT](https://img.shields.io/badge/license-MIT-gold.svg)](LICENSE)
[![GitHub stars](https://img.shields.io/github/stars/WhiteBite/Domain-Hunter?style=social)](https://github.com/WhiteBite/Domain-Hunter/stargazers)

**Свободные домены за секунды — прямо из браузера.** Открытый инструмент для охоты за доменами: массовая проверка через RDAP (без серверов и API-ключей), пять генераторов имён, живые цены регистраторов с TCO, TLD-хаки и экспорт CSV.

**[▶ Открыть приложение](https://whitebite.github.io/Domain-Hunter/)** — работает сразу, ничего устанавливать не нужно.

## Фичи

- **Массовая проверка** — до 3000 имён за раз; с расширением по выбранным зонам выходит до 30 000 проверок, результаты стримятся в таблицу. Прерванный запуск можно продолжить.
- **140+ зон** — `com net io ai dev app xyz me co uk de nl fr ch so ly tech site online store cloud` и ещё 120+, на 17 реестровых инфраструктурах. Новые зоны подхватываются автоматически через живой IANA-бутстрап.
- **Честные статусы** — `available` / `probably_available` / `unknown`. Для ccTLD с ненадёжным RDAP 404 подтверждается через DNS-over-HTTPS (Cloudflare + Google DNS). Инструмент никогда не «угадывает» доступность.
- **Пять генераторов** — комбинатор «корни × аффиксы», мешалка слогов с оценкой благозвучности (на базе CMUdict), тематические наборы со смыслом слов, TLD-хаки (`family` → `fami.ly`) и мутации слов (`midas` → `mydas`, `midaz`, `midaso`).
- **Цены и TCO** — первый год и продление (Porkbun и Cloudflare, офлайн-снапшот в резерве), купоны, детект «промо-ловушки» (продление ≥ 5× первого года), сортировка по 3-летнему TCO, ссылки на покупку у 12 регистраторов. Цены в $, ₽ или €.
- **Вежливость к реестрам** — AIMD-лимиты на каждую инфраструктуру (строгий ~1 запрос/с для Google Registry соблюдается), backoff на 429 с учётом `Retry-After`, кэш результатов в localStorage.
- **Шаринг и экспорт** — ссылки `#s=` (запрос + зоны, автостарт проверки), CSV-экспорт в Excel-совместимом формате, копирование и перепроверка каждой строки.
- **Приватность** — без аналитики, телеметрии и аккаунтов. Всё состояние — в `localStorage` вашего браузера. Двуязычный интерфейс (EN/RU), светлая и тёмная темы, мобильная вёрстка.

## Быстрый старт

Сборка — один самодостаточный HTML-файл:

- **Хостинг:** <https://whitebite.github.io/Domain-Hunter/>
- **Локально:** откройте [`dist/index.html`](dist/index.html) прямо с диска (`file://` полностью поддерживается).
- **Собрать из исходников:**

```bash
npm install
npm run build     # соберёт dist/index.html — один файл, всё внутри
npm run dev       # dev-сервер Vite для разработки
```

Ни бэкенда, ни переменных окружения, ни API-ключей — вообще.

## Деплой своей копии

**GitHub Pages** (проще всего):

1. Форкните репозиторий.
2. Settings → Pages → Source: **GitHub Actions** (входящий в репозиторий `deploy.yml` сам соберёт и опубликует сайт при каждом пуше в `main`).
3. Ваша копия будет на `https://<вы>.github.io/Domain-Hunter/`.

**Cloudflare Pages:** импортируйте репозиторий, build command — `npm run build`, output — `dist`.

**Любой статический хостинг или диск:** отдайте или откройте `dist/index.html`. Все пути относительные (`base: './'`), работает под любым подпутём.

## Как это работает

1. Браузер обращается **напрямую к RDAP-эндпоинтам реестров** (Verisign, Google, Identity Digital, Radix, CentralNic…). У всех используемых эндпоинтов открыт CORS, поэтому сервер не нужен.
2. **HTTP 200 → домен занят**, **404 → нет в реестре** (дальше правила доверия: для gTLD с высоким доверием — `available`; для ccTLD 404 перепроверяется через DoH и выдаётся `probably_available`).
3. **429 / 5xx → повтор с backoff**; при постоянных сетевых/CORS-сбоях можно подключить опциональный Cloudflare Worker-прокси (настраивается в приложении).
4. Результаты кэшируются в localStorage (TTL настраивается), запросы идут с паузами на зону — вежливо к реестрам.

## Поддерживаемые зоны

147 курируемых зон по инфраструктурам: Verisign (`com net cc tv`), Google Registry (`dev app page new day how ing meme zip mov foo dad phd prof esq nexus rsvp soy boo channel`), Identity Digital (`io ai me sh ac pro info` и 70+ других), CentralNic (`xyz lol icu cyou bond sbs cfd art` и 30+), Radix (`tech site online fun space store website press host`), Uniregistry (`cloud link top win bid loan men`), плюс выделенные ccTLD-эндпоинты (`de co us uk nl fr ch ru so ly`). Живой IANA-бутстрап добавляет новые gTLD автоматически.

Нужна зона, которой нет? Всё data-driven — достаточно добавить запись в `src/config/tlds.json`, код трогать не нужно.

## Нюансы и честность

- Проверка — «моментальный снимок»: домен могут увести через минуту после проверки. Покупайте оперативно.
- Цены ориентировочные; у некоторых зон — оценка. Перед покупкой смотрите корзину регистратора.
- Некоторые зоны (.ai) требуют минимальный срок 2 года — учтено в цене.
- Премиум-домены (словарные слова) могут стоить дороже таблицы — реестр покажет это только при покупке.
- RDAP некоторых ccTLD может не отвечать из отдельных сетей/стран (гео-блоки). Для таких случаев — Worker-прокси.

## Технологии

Svelte 5 + TypeScript (strict), Vite 7, `vite-plugin-singlefile` — всё приложение (JS, CSS, шрифты, Web Worker) компилируется в **один HTML-файл**, который работает даже с `file://`. Тесты — Vitest, деплой — GitHub Actions на GitHub Pages.

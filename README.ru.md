Свободные домены за секунды — прямо из браузера. Открытый инструмент для массовой проверки доступности доменных имён и генерации новых: 148+ зон, RDAP напрямую (альтернатива WHOIS), пять генераторов имён, живые цены регистраторов с TCO, экспорт в CSV/TSV/Markdown. Без серверов, без API-ключей, без отслеживания.

**[▶ Открыть приложение](https://whitebite.github.io/Domain-Hunter/)** — работает сразу, ничего устанавливать не нужно.

![Domain Hunter проверяет пять брендовых имён по 15 зонам — стриминг результатов со статусами, ценами первого года и продления, экспорт CSV](docs/screenshot-en-check.png)

Domain Hunter обращается к **RDAP**-эндпоинтам реестров напрямую из браузера (Verisign, Google Registry, Identity Digital, CentralNic, Radix…) и сообщает, какие домены свободны. Генерирует брендовые идеи пятью встроенными генераторами, показывает **живые цены регистраторов** с трёхлетним TCO и экспортирует всё в CSV, TSV или Markdown. Это приватная альтернатива сервисам WHOIS-поиска и платным доменным API вроде WhoisXML или DomainTools — всё приложение компилируется в один самодостаточный HTML-файл, который работает и с `file://`.

## Как проверить доступность доменов оптом

Вставьте до 3 000 доменных имён, выберите нужные зоны и нажмите «Старт». Результаты стримятся в сортируемую таблицу со статусами, колонками цен и ссылками на покупку. Прерванный запуск можно продолжить позже.

- **148 курируемых зон** на 18 реестровых инфраструктурах (`com net io ai dev app xyz me co uk de nl fr ch so ly tech site online store cloud` и ещё больше). Новые gTLD подхватываются автоматически через живой IANA-бутстрап.
- **Честные три состояния** — `available`, `probably_available` или `unknown`. Для ccTLD с ненадёжным RDAP 404 подтверждается через DNS-over-HTTPS (Cloudflare + Google DNS) перед тем как что-то назвать свободным. Инструмент никогда не «угадывает».
- **Фоллбэк Cloudflare RDAP** — когда первичный RDAP-запрос падает, один раз опрашивается `rdap.cloudflare.com/domain/{domain}` как транспортный фоллбэк и как перекрёстная проверка на противоречие для low-trust зон. Занятый домен не может быть помечен как свободный.
- **Вежливость к реестрам** — AIMD-лимиты на каждую инфраструктуру (строгий ~1 запрос/с для Google Registry соблюдается), backoff на 429 с учётом `Retry-After`, кэш результатов в `localStorage`.

## Как сравнить цены доменов у разных регистраторов

**Вкладка Цены** показывает матрицу TLD × регистратор с подсветкой самой дешёвой ячейки, флагами промо-ловушек (продление ≥ 5× первого года) и экспортом в CSV. В таблице результатов есть раскрывающаяся детальная строка с полным сравнением цен регистраторов и кликабельными ссылками покупки/поиска для каждого свободного домена.

- **Живые цены** от Porkbun и Cloudflare at-cost плюс еженедельные снапшоты Dynadot, Spaceship, ValueDomain, reg.ru и Beget, собираемые через regctl.sh.
- **Купоны, детект промо-ловушек**, сортировка по 3-летнему TCO. Цены в $, ₽ или €.
- **Ссылки покупки с учётом покрытия** ведут на самого дешёвого регистратора с шаблоном глубокой ссылки, а не просто на минимальную цену в таблице.

## Как найти идеи доменных имён, которые реально свободны

Пять генераторов создают кандидаты, которые можно проверить мгновенно:

1. **Комбинатор** — корни × аффиксы (префикс, суффикс, оба)
2. **Мешалка слогов** — неологизмы с оценкой благозвучности из банков слогов CMUdict
3. **Тематические наборы** — курируемые категории (технологии, природа, мифология, цвета, созвездия)
4. **TLD-хаки** — `family` → `fami.ly` через хакабельные зоны
5. **Мутации слов** — замена гласных, согласных, усечение, суффиксы

Каждый кандидат попадает в персистентный лоток, который переживает переключение табов и заранее показывает проектное число проверок.

## Экспорт, шаринг и организация

- **CSV-файл** — совместимый с Excel формат с BOM и корректным экранированием
- **Копировать как CSV / Markdown / TSV** — форматы для буфера обмена, удобные для вставки в таблицы, документы или Notion
- **Массовые действия для свободных доменов** — скопировать список всех свободных, добавить все в избранное одним кликом, экспортировать CSV только свободных
- **Ссылки шаринга** — `#s=` кодирует запрос + зоны и автостартует проверку при открытии
- **Избранное с наблюдением** — отметьте домен звездой; при перезагрузке появляются бейджи освобождения или занятия
- **История запусков** — недавние завершённые проверки сохраняются локально; клик восстанавливает весь поиск (запрос, зоны, результаты) в одно нажатие
- **Восстановление последнего поиска** — после перезагрузки страницы приложение возвращает ваш предыдущий ввод и выбор зон, чтобы можно было продолжить мгновенно
- **Проверка соцсетей с GitHub-токеном** — вкладка Social поддерживает опциональную аутентификацию через GitHub device-flow для более частых проверок никнеймов
- **Бейджи с фавиконками регистраторов** — ячейки цен показывают логотипы регистраторов рядом с ценами для быстрого визуального сканирования

## Как это работает

1. Браузер обращается **напрямую к RDAP-эндпоинтам реестров** (Verisign, Google, Identity Digital, Radix, CentralNic…). У всех используемых эндпоинтов открыт CORS, поэтому сервер не нужен.
2. **HTTP 200 → домен занят**, **404 → нет в реестре** (дальше правила доверия: для gTLD с высоким доверием — `available`; для ccTLD 404 перепроверяется через DoH и выдаётся `probably_available`).
3. **429 / 5xx → повтор с backoff**; при постоянных сетевых/CORS-сбоях сначала пробуют Cloudflare RDAP, затем DoH-корроборацию.
4. Результаты кэшируются в localStorage (TTL настраивается), запросы идут с паузами на зону — вежливо к реестрам.

## Поддерживаемые зоны

148 курируемых зон по инфраструктурам: Verisign (`com net cc tv`), Google Registry (`dev app page new day how ing meme zip mov foo dad phd prof esq nexus rsvp soy boo channel`), Identity Digital (`io ai me sh ac pro info live world email studio agency` и 54 других), CentralNic (`xyz lol icu cyou bond sbs cfd art` и 21 больше), Radix (`tech site online fun space store website press host uno pw`), Uniregistry (`cloud link top win bid loan men`), выделенные ccTLD-эндпоинты (`de co us uk nl fr ch ru so ly pl`) и NASK Польша (`pl`). Живой IANA-бутстрап добавляет новые gTLD автоматически.

Нужна зона, которой нет? Всё data-driven — достаточно добавить запись в `src/config/tlds.json`, код трогать не нужно.

## Domain Hunter vs аналоги

| | Domain Hunter | Поисковики регистраторов | `whois` CLI | Платные API (WhoisXML, DomainTools) |
|---|---|---|---|---|
| Цена | Бесплатно, MIT | Бесплатно (привязка к одному регистратору) | Бесплатно | От ~$19/мес |
| Массовая проверка | 3 000 имён × 148+ зон | По одному | Нужен скрипт | Да, лимитировано |
| Серверы / API-ключи | **Не нужны — работает в браузере** | Н/Д | Локальная установка | API-ключ + биллинг |
| Генераторы имён | 5 встроенных | Базовые подсказки | Нет | Нет |
| Живые цены + 3-летний TCO | Сравнение нескольких регистраторов | Только свои цены | Нет | Доплата |
| Форматы экспорта | CSV, TSV, Markdown, ссылки шаринга | Нет | Вручную | Зависит |
| Приватность | Без отслеживания, локально | История поиска логируется | Приватно | Логи запросов |

Выбирайте платное API, если нужны гарантированные SLA, прайс-фиды премиум-доменов или миллионы проверок в день. Выбирайте Domain Hunter, когда хотите быстро, бесплатно и приватно перебрать сотни кандидатов прямо сейчас.

## Вопросы и ответы

### Как проверять домены без сервера и API-ключа?

Реестры открывают RDAP (Registration Data Access Protocol, современный наследник WHOIS) поверх HTTPS, а эндпоинты, которые использует Domain Hunter, отправляют разрешающие CORS-заголовки. Ваш браузер вызывает их напрямую, точно так же как любой публичный API. Для stubborn-эндпоинтов можно подключить опциональный Cloudflare Worker-прокси.

### Насколько точен статус "available"?

Для ICANN-контрактированных gTLD-инфраструктур (Verisign, Google, Identity Digital…) RDAP 404 авторитетен. Для ccTLD с менее надёжным RDAP Domain Hunter перепроверяет через DNS NS-запросы по DoH и выдаёт `probably_available`, не преувеличивая. Домен могут увести через минуту после проверки — это моментальный снимок, покупайте оперативно.

### Законна и вежлива ли проверка через RDAP?

Да. RDAP — это собственный публичный машиночитаемый интерфейс реестров (он создан именно чтобы заменить спаршенный WHOIS). Domain Hunter распределяет запросы по инфраструктурам, уважает `Retry-After` и замедляется экспоненциально при throttle — например, Google Registry получает не более ~1 запроса в секунду. Глобальный лимит параллельности держит всё в рамках.

### Что такое промо-ловушка и почему важна цена продления?

Некоторые регистраторы рекламируют первый год за $0.99, но берут $25 за продление. Domain Hunter помечает такие как **промо-ловушки**, когда цена продления в 5 раз и более превышает первый год. Всегда смотрите колонку продления и 3-летний TCO, а не только стартовую цену.

### Поддерживаются ли IDN и ccTLD вроде .ru или .de?

Международные доменные имена автоматически конвертируются в punycode. `de co us uk nl fr ch ru so ly pl` поддерживаются через выделенные RDAP-эндпоинты (`ru` помечена экспериментальной из-за гео-ограничений на её RDAP — опциональный прокси-фоллбэк покрывает такие случаи).

### Может ли работать офлайн или с диска?

Да. Продакшн-сборка — один файл `index.html`, который работает из `file://` без единого сетевого запроса. Данные цен падают на встроенный снапшот; проверки доступности требуют сети для доступа к RDAP-эндпоинтам.

### Как определяется "available" для ccTLD?

404 от ccTLD запускает два параллельных чека: DNS-over-HTTPS NS-зонд (Cloudflare + Google DNS) и, когда доступен, запрос Cloudflare RDAP-агрегатора. Если агрегатор возвращает 200, домен помечается `taken` независимо от результата DoH. Иначе результат DoH остаётся: NXDOMAIN → `probably_available`, NOERROR → `taken`, другое → `unknown`.

### Где хранятся мои данные?

Только в вашем браузере. Настройки, кэш, избранное и пользовательские наборы слов живут в `localStorage` под ключами `dh:v1:*`. Никакого аккаунта, серверного состояния и аналитики любого вида.

## Технологии

Svelte 5 + TypeScript (strict), Vite 7, `vite-plugin-singlefile` — всё приложение (JS, CSS, шрифты, Web Worker) компилируется в **один HTML-файл**, который работает даже с `file://`. Тесты — Vitest для логики и Playwright E2E (с замоканной сетью) для UI; деплой — GitHub Actions на GitHub Pages.
